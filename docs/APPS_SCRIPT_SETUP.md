# Apps Script 설치·배포 안내

Niro Manager는 차계부 스프레드시트에 연결된 Apps Script 웹 앱으로 동작합니다. Google Cloud 프로젝트, OAuth 클라이언트, API 키는 필요 없습니다. 웹 앱은 소유자 계정으로 실행되고 소유자만 열 수 있어, 브라우저에 Google 계정으로 로그인되어 있으면 앱에서 따로 로그인하지 않습니다.

## 1. 올릴 파일 받기

다음 세 파일이 필요합니다: `index.html`, `Code.js`, `appsscript.json`.

- GitHub: 저장소 **Actions → CI → 최근 main 실행 → Artifacts → `apps-script`** 를 내려받아 압축을 풉니다.
- 또는 직접 빌드: Node.js 22 이상에서 `npm ci && npm run build` 후 `dist/` 폴더.

## 2. 테스트 복사본에 먼저 설치

1. Google Drive에서 테스트용 복사본을 엽니다. 2026-10-25 기준 복사본이 없으므로, 필요하면 원본 `히로_차계부_DB`에서 **파일 → 사본 만들기**로 이름에 "복사본"이 들어간 파일(예: `히로_차계부_DB (테스트 복사본)`)을 만듭니다.
2. **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기의 `Code.gs` 내용을 모두 지우고 `Code.js` 내용을 붙여 넣습니다.
4. 파일 옆 **+ → HTML**로 이름이 `index`인 파일을 만들고, `index.html` 내용을 모두 붙여 넣습니다. 이름은 `index`여야 합니다.
5. **프로젝트 설정(톱니바퀴) → "편집기에서 appsscript.json 매니페스트 파일 표시"**를 켜고, 편집기의 `appsscript.json` 내용을 받은 `appsscript.json`으로 바꿉니다. Sheets 고급 서비스, 시간대(서울), 웹 앱 설정이 들어 있습니다.
6. 저장(Ctrl+S)합니다.

## 3. 웹 앱으로 배포

1. **배포 → 새 배포 → 유형 선택(톱니) → 웹 앱**.
2. 다음 사용자 인증 정보로 실행: **나**, 액세스 권한이 있는 사용자: **나만**.
3. **배포**를 누르고 권한을 승인합니다. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 눌러 본인 스크립트를 허용합니다.
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 엽니다.
5. 기록 목록과 상단의 "테스트 복사본" 배지를 확인하고, 입력 화면에서 주유 한 건을 저장한 뒤 시트에서 확인합니다. 확인용 행은 확인 후 지웁니다.

## 4. 원본에 설치

원본 `히로_차계부_DB`에서 2~3단계를 똑같이 진행합니다(2026-10-25 이미 설치·배포됨). 상단 배지가 "원본 · 저장 가능"으로 보이면 원본에 연결된 것입니다. 휴대폰에는 아래 5절의 런처로 앱처럼 설치합니다.

## 5. 휴대폰에 앱으로 설치

Apps Script 주소(`script.google.com`)에는 앱 설치 정보(manifest)를 붙일 수 없어 Android Chrome에서 "이 앱을 설치할 수 없습니다"가 뜹니다. 그래서 GitHub Pages에 **설치용 입구 페이지(런처)** `https://niro-manager.github.io/niro-manager/`를 두었습니다. 런처는 이 기기에 저장한 웹 앱 주소를 열기만 하며, 기록을 읽거나 저장하지 않습니다.

**먼저(한 번만)**: 런처가 웹 앱을 화면 안에 끼워 넣을 수 있도록, 최신 `Code.js`로 `Code.gs`를 바꾸고 **새 버전으로 재배포**합니다(아래 "업데이트" 절차, URL 유지). 2026-10-25 이전 `Code.gs`로는 끼워 넣은 화면이 "연결을 거부했습니다"로 뜹니다.

1. Apps Script 편집기에서 **배포 → 배포 관리**를 열고 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)을 복사합니다. 끝이 `/dev`인 테스트 주소가 아니라 `/exec` 주소여야 합니다.
2. 휴대폰 Chrome으로 런처 주소를 열고 웹 앱 URL을 붙여 넣은 뒤 **저장하고 열기**를 누릅니다. 주소와 열기 방식은 이 기기의 브라우저에만 저장되고 저장소에는 올라가지 않습니다.
3. "저장했습니다" 화면에서 설치합니다.
   - Android Chrome: 메뉴(⋮) → **앱 설치**(또는 **홈 화면에 추가 → 설치**)
   - iPhone Safari: 공유 → **홈 화면에 추가**
4. 홈 화면(Android는 앱 서랍에도)의 **니로 차계부** 아이콘으로 엽니다.

### 열기 방식

런처 설정 화면(`?setup=1`)에서 기기별로 고릅니다.

- **끼워 넣기(기본)**: 런처 화면 안에 웹 앱을 테두리 없이 전체 화면으로 띄웁니다. 웹 앱이 다른 주소로 넘어가지 않으므로 Chrome의 "앱 밖 페이지" 표시줄(`script.google.com`)이 생기지 않습니다. Google의 "이 애플리케이션은 Google Apps Script 사용자가 만들었습니다" 배너도 끼워 넣은 화면에서는 보이지 않습니다(2026-10-25 Android Chrome 설치 앱에서 확인, iPhone은 미확인).
- **직접 열기**: 웹 앱 주소로 이동합니다(예전 방식). 위쪽에 주소 표시줄이 남지만 끼워 넣기가 안 될 때도 열립니다.

끼워 넣은 화면 오른쪽 아래의 작은 **↗** 단추를 누르면 **직접 열기**와 **설정**이 나옵니다. 끼워 넣은 화면이 흰 화면이거나 "연결을 거부했습니다"로 보이면 이 단추로 직접 엽니다. 10초가 지나도 화면이 불러와지지 않으면 런처가 **직접 열기**와 **이 기기에서는 항상 직접 열기**를 보여줍니다.

참고:

- iPhone Safari는 다른 사이트에 끼워 넣은 화면의 Google 로그인 쿠키를 막아, 끼워 넣기가 흰 화면이나 로그인 화면으로 보일 수 있습니다. iPhone에서는 **직접 열기**를 고르세요. 또 iPhone은 홈 화면 앱이 Safari와 저장소를 따로 써서, 설치한 앱을 처음 열 때 주소를 한 번 더 붙여 넣어야 할 수 있습니다.
- Android에서도 Chrome의 서드파티 쿠키를 차단하도록 설정했다면 끼워 넣기에서 로그인이 풀릴 수 있습니다. 그때는 **직접 열기**를 씁니다.
- 주소나 열기 방식을 바꾸거나 주소를 지우려면 브라우저로 `https://niro-manager.github.io/niro-manager/?setup=1`을 엽니다(설치한 앱에서는 ↗ → 설정). 웹 앱을 "새 배포"로 다시 만들어 URL이 바뀐 경우에만 주소를 바꾸면 됩니다.
- 인터넷이 끊겨 있으면 런처가 "오프라인입니다"를 보여주고, 연결되면 자동으로 웹 앱을 엽니다.
- 예전에 GitHub Pages 앱(PWA)을 설치했다면 같은 앱으로 인식되어 그 아이콘이 런처로 바뀝니다.

## 6. 영수증 사진으로 주유 입력 채우기

**입력 → 주유**에서 **영수증 사진 찍기**(카메라) 또는 **사진 고르기**(갤러리)를 누르면, 사진의 글자를 Google Drive 글자 인식(OCR)으로 읽어 날짜·단가·리터·결제 금액 칸을 채웁니다.

- 채운 칸에는 "영수증에서 읽음" 표시가 붙습니다. 인식이 틀릴 수 있으니 값을 확인하고, 평소처럼 **확인 → 저장**을 직접 누릅니다. 사진만으로 자동 저장하지 않습니다.
- 결제 금액이 단가×리터(원 단위 반올림)와 다르면(할인·상품권 등) "결제액이 단가×리터와 다름"을 켜고 결제 금액을 넣습니다. 같으면 평소처럼 단가×리터 수식으로 저장합니다.
- 찾지 못한 값은 칸을 비우고 "찾지 못함"으로 알려 줍니다. 날짜를 못 찾으면 원래 날짜(오늘)를 그대로 둡니다. 누적 km·비고는 바꾸지 않습니다.
- **인식한 글자 보기**를 펼치면 읽은 글자 전체를 볼 수 있습니다. 이 글자와 사진은 화면에만 있고 시트·기기·로그에 저장하지 않습니다.
- 사진은 휴대폰에서 긴 변 1600px 정도로 줄여 보내고, 서버는 Drive에 "Niro Manager 영수증 인식(임시)" 문서를 잠깐 만들어 글자를 꺼낸 뒤 휴지통을 거치지 않고 바로 지웁니다. 지우지 못하면 앱이 알려 주니 Drive에서 그 문서를 직접 지웁니다.
- 지금은 주유 영수증만 지원합니다. 처음에는 흔한 주유소 양식을 흉내 낸 예시로 규칙을 만들었으므로, 실제 영수증에서 자주 틀리면 알려 주세요.

## 업데이트

새 버전을 받으면 다음 순서로 올립니다. 이렇게 하면 웹 앱 URL이 그대로 유지되어 런처에 저장한 주소도 바꿀 필요가 없습니다.

1. Apps Script 편집기에서 `index`, `Code.gs`(및 바뀐 경우 `appsscript.json`)의 내용을 새 파일 내용으로 모두 바꿔 붙여 넣고 저장합니다.
2. **배포 → 배포 관리**를 엽니다.
3. 기존 웹 앱 배포의 **연필(수정)**을 누릅니다.
4. **버전: 새 버전**을 고르고 **배포**를 누릅니다.

"새 배포"를 만들면 URL이 바뀝니다(그때는 런처 `?setup=1`에서 주소를 다시 넣어야 함).

### 영수증 사진 인식 버전으로 올릴 때(2026-10-25)

이 버전부터 `appsscript.json`이 바뀝니다(Drive 고급 서비스 추가, 권한 목록 명시). **세 파일(`index`, `Code.gs`, `appsscript.json`)을 모두** 바꿔 붙여 넣은 뒤 위 1~4단계로 새 버전을 배포합니다.

- 권한이 늘어 다시 승인해야 할 수 있습니다. 웹 앱을 열 때 "권한 필요" 화면이 나오면 **권한 검토 → 계정 선택 → 고급 → (프로젝트 이름)(으)로 이동 → 허용**을 누릅니다. 화면이 나오지 않고 영수증 인식만 "권한" 오류로 실패하면, 편집기에서 함수 목록의 `getInfo`를 한 번 **실행**해 승인 창을 띄웁니다.
- 앱이 요청하는 권한: 스프레드시트(차계부 읽기·쓰기), **이 앱이 만든 Drive 파일만**(`drive.file`, 영수증을 잠깐 문서로 바꾸고 바로 지우는 데 사용), 외부 요청(`script.external_request`, 그 문서에서 글자를 꺼내는 Drive 요청에 사용). Drive의 다른 파일에는 접근하지 않습니다.
- 편집기의 **서비스**에 Drive API가 보이지 않으면 **서비스 + → Drive API(v3) → 추가**를 누릅니다(`appsscript.json`을 바꿔 붙여 넣으면 보통 자동으로 추가됩니다).

명령줄을 쓰려면 [clasp](https://github.com/google/clasp)로 `dist/`를 올릴 수 있습니다(`rootDir: dist`). 이때 [Apps Script 사용자 설정](https://script.google.com/home/usersettings)에서 Apps Script API를 켜야 합니다. `.clasp.json`의 스크립트 ID는 저장소에 커밋하지 않습니다.

## 문제 해결

- **영수증 인식이 "권한"·"Drive" 오류로 실패**: 영수증 인식 버전의 `appsscript.json`을 올리고 새 버전으로 배포했는지, 늘어난 권한을 승인했는지 확인합니다(위 "영수증 사진 인식 버전으로 올릴 때").
- **런처 앱 화면에 찡그린 문서 아이콘(Chrome 오류)이 뜸**: 웹 앱이 아직 끼워 넣기를 허용하지 않는 옛 `Code.gs`로 배포되어 있습니다. 최신 `Code.js`로 `Code.gs`를 바꾸고 **배포 관리 → 연필 → 버전: 새 버전 → 배포**로 재배포한 뒤 런처 앱을 다시 엽니다. 급하면 오른쪽 아래 ↗ → **직접 열기**로 엽니다.
- **흰 화면이나 "권한 필요" 오류**: 브라우저에 여러 Google 계정이 로그인되어 있으면 Apps Script 웹 앱이 다른 계정으로 열려 실패할 수 있습니다. 시크릿 창에서 소유자 계정만 로그인하거나, 계정을 하나만 남기고 다시 엽니다.
- **"탭을 찾을 수 없습니다"**: 설정 화면의 주유·정비 탭 이름이 시트와 같은지 확인합니다.
- **"서버 함수 …이(가) 없습니다"**: `Code.gs`가 최신인지 확인하고 새 버전으로 다시 배포합니다.
- **"허용하지 않는 시트 변경 요청"**: 서버는 행 끼워 넣기·서식 복사·셀 값 쓰기만 허용합니다. 앱과 `Code.gs` 버전이 맞는지 확인합니다.

## 이전 방식 정리(선택)

Google Cloud 설정은 더 이상 쓰지 않습니다. 원하면 Google Cloud 콘솔에서 이 앱용 OAuth 클라이언트와 API 키를 삭제하고, GitHub Variables의 `VITE_GOOGLE_*` 값도 지워도 됩니다. GitHub Pages는 런처 배포에 다시 쓰므로 끄지 않습니다. 저장소 **Settings → Pages → Source**가 **GitHub Actions**인지 확인합니다.
